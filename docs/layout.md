# 配置図（layout.json）の書き方

`events/<eventId>/layout.json` があるイベントだけ配置図を表示します。公式配置図を見ながら座標を描き起こします（公式画像は転載しない）。
座標はホール左上を原点とした任意の単位で、セル（1スペース）の既定の大きさは 45×26 です。

```jsonc
{
  "$comment": "出典の公式配置図の URL など（ページには出ない）",
  "expectedSpaces": 43,                        // 任意。スペース数がこれと違えば pnpm data がエラーにする
  "cell": { "w": 45, "h": 26 },                // 任意。セルの大きさ
  "hall": { "x": 0, "y": 0, "w": 1000, "h": 600 },     // ホールの外枠
  "bounds": { "x": -40, "y": -20, "w": 1080, "h": 640 }, // 任意。拡大・移動できる範囲（既定はホール＋出入口の周り）
  "focus": { "x": 60, "y": 60, "w": 560, "h": 420 },     // 任意。最初と「島」ボタンで表示する範囲（既定は全セルの周り）
  "islands": [
    { "name": "A", "x": 100, "y": 100, "rows": 10, "columns": 2 },
    { "name": "B", "x": 300, "y": 100, "rows": 10, "columns": 2, "order": "down-up" },
    { "name": "C", "x": 500, "y": 100, "rows": 2, "columns": 1, "start": 5 }
  ],
  "cells": [                                   // 任意。島の形に収まらないスペースを1つずつ置く
    { "space": "壁-01", "x": 600, "y": 60, "w": 90 }
  ],
  "entrances": [{ "label": "出入口", "rect": { "x": -20, "y": 450, "w": 36, "h": 100 } }],
  "landmarks": [
    { "label": "本部", "rect": { "x": 600, "y": 500, "w": 200, "h": 60 }, "kind": "facility" },
    { "label": "待機列", "points": [[0,0],[100,0],[100,50]], "kind": "queue" }
  ]
}
```

## 島（islands）

| キー | 内容 |
|---|---|
| `name` | 島の記号。スペース番号は `name` + `separator` + 番号 |
| `x`, `y` | 島の左上 |
| `rows` | 1列あたりのスペース数 |
| `columns` | `1` または `2` |
| `start` | 最初の番号（既定 1） |
| `separator` | 記号と番号の区切り（既定 `-`。`A01` なら `""`） |
| `digits` | 番号の桁数（既定 2） |
| `order` | 番号の振り方（下表） |
| `label` | 島の記号の位置。`"auto"`（既定）・`"none"`・`{ "x", "y", "anchor" }` |

| columns | order | 番号の振り方 |
|---|---|---|
| 2 | `up-down`（既定） | 左列を下から上へ、続けて右列を上から下へ（コの字） |
| 2 | `down-up` | 左列を上から下へ、続けて右列を下から上へ |
| 2 | `right-left` | 横向きの島。上の行を左から右へ、続けて下の行を右から左へ |
| 2 | `left-right` | 横向きの島。上の行を右から左へ、続けて下の行を左から右へ |
| 1 | `down`（既定） / `up` | 縦1列。上から／下から |
| 1 | `right` / `left` | 横1列。左から／右から |

番号の振り方が公式と違うと、サークルの位置がずれます。公式配置図の角の番号（例: 島の四隅）と見比べてください。

## landmarks の kind

| kind | 用途 |
|---|---|
| `queue` | 待機列（ラベルは縦書き） |
| `facility` | 受付・本部・販売所など |
| `company` | 企業ブース |
| `area` | 休憩所・企画エリア |
| `other-event` | 同じホールの別イベント区画（破線の枠） |

## 確かめる

- `pnpm data <eventId>` — スペースの重複、`expectedSpaces`、circles.csv のスペースが配置図にあるか
- `pnpm test` — 生成済みの全イベントの配置図
- `pnpm dev <eventId>` で、公式配置図と並べて目で確かめる
